Title, description and Topics; the name is never a field. - Create: typing the title asks the server for the name it gives (#dataset-form-name, login:dataset-name-preview) after a 300 ms pause, and that answer also replaces the Create button (dataset_form_submit.html), enabled only while the name is available. Topics are optional, with a note that one is needed to publish. - Edit: the name is shown fixed, the stored Topics are ticked, and Save is always enabled: a save that changes nothing writes nothing. A refused save (400) comes back here with what was typed (``values``) and each error beside its field (``errors``); a Topic offered nowhere is named in the Topics error and is not ticked again. A done save closes the dialog (``datasets-changed``). Bootstrap modals ignore ``autofocus``, so dash_list.js moves focus to the title once the dialog is shown. {% endcomment %} {% url 'login:dataset-action' profile_user.pk action as save_url %}
