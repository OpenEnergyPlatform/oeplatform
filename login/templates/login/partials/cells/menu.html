Edit metadata and Upload data link to the existing pages; every action on the Table itself opens the one action dialog (#table-action) with this Table as a batch of one. "Manage access" opens the access drawer (#table-access), for every role: below Admin the drawer is read-only. "Remove from dataset…" is offered only when one of the user's own Datasets holds the Table, so its choice is never empty. Delete comes last, set apart and in red. An action above the user's role stays in the menu, marked aria-disabled="true" with the reason as visible text, and tables_tab.js guards its click. Not Bootstrap's .disabled: the dropdown's keyboard navigation skips those, so the reason would be unreachable by keyboard. The menu is positioned fixed so the table's horizontal scroll container does not clip it. The toggle's id, menu-, is where focus returns after an action on this row.
