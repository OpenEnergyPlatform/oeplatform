# Release Info

The release information shown on the homepage is a short summary of the most
important updates of the latest platform release. It is meant to keep users
informed about recent changes in a simple and accessible way.

## Overview

The homepage release section provides a quick overview of developments that have
been added, improved, or fixed in the platform. Instead of showing the full
changelog, it highlights the most relevant updates in a compact form.

## What this section communicates

The content of the release information can include different kinds of updates,
for example:

- New or improved functionality that makes the platform easier to use.
- Changes to workflows, interfaces, or navigation that improve the user
  experience.
- Updates related to data handling, metadata, or platform integrations.
- Improvements in the way information is displayed or structured on the website.
- Bug fixes and general refinements that increase stability and reliability.

## Purpose

This section helps users understand what changed since the last release and what
is now available or improved. It acts as a brief overview for users who want a
fast summary without reading the complete release notes.

## Implementation

The homepage release section is generated from the latest published changelog.
This ensures that the displayed information stays current and does not require a
separate manually maintained text file.
